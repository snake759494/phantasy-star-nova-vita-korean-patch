# 글꼴 출처

원본 일본어 글꼴이 고딕 계열이라 한글도 고딕 계열로 맞췄습니다. 아주 작은 그림 글자만 비트맵 글꼴(갈무리)을 썼습니다.

| 용도 | 한글 글꼴 |
| --- | --- |
| 대사·메뉴 메시지 글리프, 동영상 자막 | 나눔스퀘어네오 Bd (`NanumSquareNeo-cBd.ttf`) |
| 그림 글자 제목·라벨 | 나눔스퀘어네오 Hv·Eb (`NanumSquareNeo-eHv.ttf`, `NanumSquareNeo-dEb.ttf`) |
| 그림 글자 본문 | 나눔스퀘어네오 Bd·Rg (`NanumSquareNeo-cBd.ttf`, `NanumSquareNeo-bRg.ttf`) |
| 타이틀 한글 부제 등 | 서울한강체 EB·M (`SeoulHangangEB.ttf`, `SeoulHangangM.ttf`) |
| 아주 작은 그림 글자 | 갈무리11 Bold (`Galmuri11-Bold.ttf`) |

- 나눔스퀘어네오: © NAVER Corp. 네이버 나눔글꼴 라이선스(https://hangeul.naver.com/font)
